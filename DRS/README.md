# DRS --- Dataset Request System

The DRS collects the dataset requests from the FCC physicists:
https://fcc-drs.web.cern.ch/

The login is open to everyone with a CERN account. Selecting the Physics
group in a request notifies the MC Production contact(s) of that group.
